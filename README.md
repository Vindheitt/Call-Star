# CallStar 0.2 — React + Vite

Русскоязычный интерфейс помощника старосты. Версия 0.2 переносит предыдущий HTML/CSS/JS-прототип на React, сохраняя дизайн и основные сценарии.

## Что работает
- демонстрационный вход (любые логин и пароль);
- календарь с переключением месяцев;
- журнал посещаемости по дате и номеру пары;
- добавление и удаление студентов;
- создание событий;
- сохранение данных в `localStorage` браузера.

> Важно: это пока фронтенд-прототип. Данные не синхронизируются между устройствами и пользователями. Не вносите реальные персональные данные студентов до подключения защищённой базы данных и авторизации.

## Запуск локально
Нужен Node.js 20 или новее.

```bash
npm install
npm run dev
```

Откройте адрес, который покажет Vite в терминале.

## Публикация на GitHub Pages
В репозитории должны находиться `package.json`, `vite.config.js`, `index.html`, папки `src/` и `.github/workflows/`.

1. Загрузите файлы проекта в корень существующего репозитория.
2. Откройте **Settings → Pages**.
3. В разделе **Build and deployment** выберите **Source: GitHub Actions**.
4. Перейдите во вкладку **Actions**, дождитесь успешного запуска workflow **Deploy CallStar to GitHub Pages**.
5. Ссылка на опубликованный сайт появится в **Settings → Pages**.

Конфигурация Vite использует `base: './'`, чтобы статические файлы корректно открывались как в корне домена, так и в репозитории GitHub Pages.

## Структура

```text
CallStar/
├── .github/workflows/deploy.yml
├── src/
│   ├── App.jsx
│   ├── main.jsx
│   └── styles.css
├── index.html
├── package.json
└── vite.config.js
```
